## Datasets
  The downloaded datasets should be placed at the 'dataset' folder. Then you can following the annotation in 'run_baselines_fund.py' and run it to reproduce the paper results. 'VS' denotes Vanilla scale scaling. 'SC' denotes only using our scale calibrating sub-module. 'SS+SC' is equivalent to out AS module, using both our scale calibrating and scaling selection sub-modules.
